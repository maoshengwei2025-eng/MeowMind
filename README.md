# 喵呜导图 MeowMind

> 喵呜导图 —— 让你的想法像猫咪一样灵活跳跃。

一个单文件、零外部依赖的思维导图工具。整个应用打包在一个 HTML 文件（`bundle.html`，约 460 KB）里，浏览器双击打开即可使用，无需安装、无需联网、数据不出本机。

## 在线使用

- 应用在线版：<https://maoshengwei2025-eng.github.io/MeowMind/>
- 产品主页（功能介绍、界面截图、下载入口）：<https://maoshengwei2025-eng.github.io/MeowMind/meowmind-app/>

## 下载

| 版本 | 文件 | 说明 |
|---|---|---|
| Windows 免安装版 | `meowmind-app/release/喵呜导图.exe` | 约 3.1 MB，Windows 10+，双击即用 |
| 跨平台离线版 | 根目录 `bundle.html` | 约 460 KB，浏览器打开即用，无需安装 |

## 目录结构

```
MeowMind/
├── index.html                    # 在线应用入口（与 bundle.html 相同）
├── bundle.html                   # 单文件应用本体
└── meowmind-app/                 # 产品主页与发布资源
    ├── index.html                # 产品主页
    ├── images/                   # Logo 与界面截图
    └── release/喵呜导图.exe      # Windows 免安装版
```
