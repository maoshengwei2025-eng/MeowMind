如何使用

善用AI，善用键盘

软件操作非常简单，用一用就会了。善用AI和键盘，创作效率会飞上天！

使用步骤

按这四个步骤操作，分分钟就能绘制一张漂亮的思维导图。

打开喵呜导图

双击那只呆萌的紫黑色猫咪头像，启动《喵呜导图》程序，也可以打开一份现有的导图文件。

说出你的需求

点画布右下角 AI 按钮，一句话说给 AI——「如何制作鱼香肉丝」，喝杯茶，整张导图即刻生成。

拖拽微调

不满意的地方，调尺寸、换颜色、改emoji… 拖拽鼠标+点几下的事情。或者，干脆让AI帮你干！

保存或导出

可以将成果保存为 mindflow 文件留档，也可一键导出 PNG / PDF 文件 直接发群里分享。

使用快捷键

内置丰富的快捷键，键盘即可操作整个绘图工作流。熟练之后，画一张导图的速度接近你打字的思考速度。

快捷键功能说明
Tab为选中节点添加子节点
Shift+Tab根节点加左侧子节点 / 其它节点加兄弟节点
Del删除选中节点及其子树
Enter编辑选中节点文本
↑↓←→在节点树之间切换选中节点
F1打开 Ai助手
F2选中节点添加"备注"
Ctrl+~折叠 / 展开 属性面板
Ctrl+C / X / V复制 / 剪切 / 粘贴 选中节点
Ctrl+/折叠 / 展开 选中节点的子树
Ctrl+[Space]缩放导图至最佳显示比例
Ctrl+Z撤销 上一步操作
Ctrl+Y重做 刚才的撤销
